# Glassmorphism Login Page

A modern login page built with HTML5 and CSS3, featuring a glassmorphism-inspired design and responsive layout.

## ✨ Features

- Responsive design
- Flexbox layout
- Glassmorphism effect
- Gradient decorative elements
- Clean and modern UI

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
